# Sicherheitsrichtlinie

Bitte veröffentlichen Sie Sicherheitslücken nicht als öffentliches GitHub-Issue.

Melden Sie Sicherheitsprobleme über:

- https://ticket.obermeier-it.de

Für den produktiven Betrieb sind HTTPS, regelmäßige Datenbank-Backups, aktuelle PHP-/MariaDB-Versionen und restriktive Dateirechte verpflichtend. Die Datei `config/config.php` enthält Zugangsdaten und darf niemals öffentlich ausgeliefert oder in Git eingecheckt werden.
